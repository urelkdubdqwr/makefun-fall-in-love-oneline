One line, at most 240 characters, that makes the judge fall in love with a person, a place, a machine or an idea. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
